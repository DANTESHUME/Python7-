# 10天英语高频词背诵互动学习网站

这是一个面向零基础/基础薄弱用户的英语高频词学习网站，旨在通过10天的密集训练，帮助用户掌握500个最常用的英文单词。

## 🚀 一键启动说明 (Windows/Mac/Linux)

本项目基于现代前端技术栈 (Vite + React)，无需后端服务，所有数据存储在本地浏览器中。

### 前置要求
确保你的电脑已安装 [Node.js](https://nodejs.org/) (建议 v18 或更高版本)。

### 启动步骤

1.  **打开终端** (Windows 用户可使用 PowerShell 或 CMD)。
2.  **进入项目目录**：
    ```bash
    cd english_vocab_10days
    ```
3.  **安装依赖**：
    ```bash
    npm install
    # 或者使用 pnpm (推荐)
    pnpm install
    ```
4.  **启动开发服务器**：
    ```bash
    npm run dev
    # 或者
    pnpm dev
    ```
5.  **访问网站**：
    打开浏览器访问终端显示的地址，通常是 `http://localhost:5173` 或 `http://localhost:3000`。

## ✨ 核心功能与验收清单

### 1. 课程设置
- [x] **10天课程**：首页仅展示 Day1~Day10，无 Day11。
- [x] **每日50词**：每天固定学习50个高频词，总计500词。
- [x] **数据驱动**：所有内容由 `data/plan.json` 驱动。

### 2. 单词学习
- [x] **IPA音标**：每个单词均展示 IPA 音标 (如 `/ˈæpəl/`)。
- [x] **一键发音**：支持 TTS (Web Speech API) 发音，带播放状态反馈。
- [x] **详细释义**：包含词性、中文释义、英文例句和中文翻译。
- [x] **记忆提示**：部分单词提供记忆辅助提示。

### 3. 互动练习
- [x] **多种题型**：包含“释义选择题”和“单词拼写题”。
- [x] **即时反馈**：答题后立即显示正误，拼写题支持首字母提示。
- [x] **自动流程**：每日学习包含“目标 -> 学习 -> 练习 -> 复盘”完整闭环。

### 4. 复习系统
- [x] **间隔重复**：基于艾宾浩斯遗忘曲线原理的简化算法。
- [x] **智能队列**：自动筛选到期需要复习的单词。
- [x] **掌握度追踪**：区分“认识”、“模糊”、“不认识”，动态调整复习间隔。

### 5. 进度管理
- [x] **本地持久化**：使用 `localStorage` 保存所有学习进度，刷新不丢失。
- [x] **进度可视化**：首页展示总进度条、已掌握单词数。
- [x] **数据重置**：支持一键重置所有进度。

## ⚠️ 常见问题与排查

### Q1: 点击发音按钮没有声音？
*   **原因**：浏览器不支持 Web Speech API 或系统静音。
*   **解决**：
    1.  检查电脑是否开启静音。
    2.  尝试使用 Chrome、Edge 或 Safari 等现代浏览器。
    3.  如果浏览器不支持，页面会弹出提示，但这不影响单词的记忆和练习功能。

### Q2: 页面显示空白或报错？
*   **原因**：依赖未安装完整或端口被占用。
*   **解决**：
    1.  尝试删除 `node_modules` 文件夹并重新运行 `npm install`。
    2.  检查终端是否有报错信息。

### Q3: 如何修改课程内容？
*   **方法**：直接编辑 `client/src/data/plan.json` 文件，修改对应的单词、例句或释义即可，无需修改代码。
