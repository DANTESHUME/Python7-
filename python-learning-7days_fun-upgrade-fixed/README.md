# 7 天 Python 互动学习网站 (为 AI 协作服务)

这是一个专为零基础用户设计的 Python 互动学习网站，旨在帮助用户在 7 天内掌握与 AI 协作所需的核心 Python 能力。

## 🚀 一键启动 (Windows 优先)

### 前置要求
1. 确保已安装 **Node.js** (建议 v18 或更高版本)。
   - 下载地址: [https://nodejs.org/](https://nodejs.org/)
   - 安装后在终端输入 `node -v` 检查是否成功。

### 启动步骤
1. **解压项目**：将压缩包解压到任意文件夹。
2. **打开终端**：
   - 在项目文件夹内，按住 `Shift` + 右键，选择“在此处打开 Powershell 窗口”或“在终端中打开”。
3. **安装依赖**：
   输入以下命令并回车（只需执行一次）：
   ```bash
   npm install
   ```
   或者如果你使用 pnpm (推荐):
   ```bash
   pnpm install
   ```
4. **启动网站**：
   输入以下命令并回车：
   ```bash
   npm run dev
   ```
   或者:
   ```bash
   pnpm dev
   ```
5. **访问网站**：
   打开浏览器，访问终端显示的地址（通常是 `http://localhost:5173`）。

## 📚 课程内容

- **Day 1**: 环境与最小脚本 (安装、变量、f-string)
- **Day 2**: 列表/字典与循环 (数据结构基础)
- **Day 3**: 条件判断 + 函数 (逻辑与封装)
- **Day 4**: 文件读写 (txt/json 处理)
- **Day 5**: 异常处理 + 调试 (让程序更健壮)
- **Day 6**: Requests 与调用 API (连接互联网)
- **Day 7**: 整合项目 (构建 AI 协作脚本)

## ✨ 功能特性

- **互动练习**：每天包含选择题、填空题或预测输出题，实时反馈。
- **进度追踪**：自动保存学习进度、练习完成情况。
- **本地存储**：所有数据保存在浏览器 localStorage 中，刷新不丢失。
- **作业与复盘**：每日小作业提交区和复盘问题记录。
- **数据导出**：支持将学习进度、笔记和错题导出为 JSON 文件。
- **新粗野主义设计**：高对比度、硬朗边框，营造专业的开发者氛围。

## 🛠️ 常见问题处理

**Q: 启动时提示 `'npm' 不是内部或外部命令...`**
A: 说明 Node.js 未安装或未添加到环境变量。请重新安装 Node.js 并确保勾选 "Add to PATH"。

**Q: 页面显示空白或报错？**
A: 
1. 检查终端是否有报错信息。
2. 尝试删除 `node_modules` 文件夹，重新运行 `npm install`。
3. 确保浏览器版本较新（推荐 Chrome 或 Edge）。

**Q: 进度丢失了怎么办？**
A: 进度保存在浏览器的 localStorage 中。如果清除了浏览器缓存或使用了无痕模式，进度会丢失。建议定期在“进度页面”导出 JSON 备份。
